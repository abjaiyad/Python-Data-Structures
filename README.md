# Python Data Structures

A hands-on learning repository covering Python's four built-in collection types. Each topic has a notes file with runnable examples, plus practice exercises.

## Topics Covered

| # | Topic | Notes File | Sections | Exercises |
|---|-------|------------|----------|-----------|
| 1 | Lists | `01-Lists/python_lists.py` | 19 | 2 |
| 2 | Tuples | `02-Tuples/python_tuples.py` | 9 | 1 |
| 3 | Sets | `03-Sets/python_sets.py` | 15 | 1 |
| 4 | Dictionaries | `04-Dictionaries/python_dictionaries.py` | 13 | 2 |

### 1. Lists
- Creating lists, positive and negative indexing
- Unpacking and slicing
- Modifying, checking, adding (`append`, `insert`), and removing (`remove`, `pop`, `del`, `clear`) items
- Copying and joining lists
- `count()`, `index()`, `reverse()`, and sorting

### 2. Tuples
- Creating tuples, length, indexing, and slicing
- Converting between tuples and lists
- Checking items and joining tuples
- Tuple methods: `count()` and `index()`
- Deleting tuples

### 3. Sets
- Creating sets, length, and checking items
- Adding, removing, and clearing items
- Converting a list to a set
- Union, intersection, and difference
- Subset, superset, symmetric difference, and disjoint sets

### 4. Dictionaries
- Key-value pairs, length, and accessing items
- Adding, modifying, and removing items
- Checking keys
- `items()`, `keys()`, `values()`, `copy()`, and `clear()`
- Deleting dictionaries

## How to Run

Requires Python 3. Run any file from the project root:

```bash
# Notes and examples
python 01-Lists/python_lists.py
python 02-Tuples/python_tuples.py
python 03-Sets/python_sets.py
python 04-Dictionaries/python_dictionaries.py

# Practice exercises
python 01-Lists/exercises/problem1.py
python 01-Lists/exercises/problem2.py
python 02-Tuples/exercises/exercise.py
python 03-Sets/exercises/set_exercise.py
python 04-Dictionaries/exercises/problem1.py
```
